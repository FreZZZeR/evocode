# Рабочий пример — включить A4A (Android Auto) кодировкой

> **Язык:** [English](a4a.md) · Русский

A4A (Android Auto / «Apps») на NBT EVO — это изменение **кодировки**: один бит в датагруппе `0x3000`.
Пример проверен на реальной машине (CAFD `00001EF6`, сборка `006.031.014`, BTLD `00001FFD`):
подписчик `evocode` воспроизводит собственный A4A-NCD E-Sys **байт-в-байт, включая подпись**.

## Координата

| параметр | датагруппа | байт | mask | shift | off → on |
|---|---|---|---|---|---|
| A4A enable | `0x3000` | `107` | `0x80` | `7` | `0x00` → `0x80` |

Переброс этого одного бита меняет содержимое, поэтому датагруппа `0x3010` (подпись) должна быть
пересчитана — ровно это и делает `evocode sign`.

## Сделать

```bash
export NBTEVO_OWN_VIN=<ваш VIN>

# сначала бэкап (это и ваш откат)
evocode read --host 169.254.199.99 -o backup.ncd

# включить A4A и переподписать (офлайн, с самопроверкой)
evocode sign backup.ncd a4a.ncd --key ncd_key.json --set 0x3000,107,1,0x80,7

# репетиция, затем запись (с воротами)
evocode write --host 169.254.199.99 --ncd a4a.ncd --key ncd_key.json          # dry run
evocode write --host 169.254.199.99 --ncd a4a.ncd --key ncd_key.json --l3-key l3_key.json --commit
```

Затем прочитайте обратно и сравните, посмотрите, как поднимается HMI. Если пункт Android Auto не
появился — A4A на этом устройстве обычно требует ещё и своего **FSC**-права (приложение `0x009C`):
кодировка — лишь половина некоторых фич. Откат в любой момент записью `backup.ncd`.

## Почему подписчику можно доверять

Воспроизведено тестами этого репозитория против реальных эталонных NCD:

```text
re-signed 0x3010 == E-Sys A4A signature (byte-exact): True
whole image       == E-Sys A4A NCD (content):         True
verifies under the car's coding key:                  True
```

Начав с нетронутой базовой кодировки, применив правку A4A и переподписав собственным восстановленным
ключом машины, получаем точно тот NCD, что производит E-Sys, — те же байты подписи. Это сильнейшая из
возможных проверок того, что реализация `BMWSigVerify` в [`evocode/coding.py`](../evocode/coding.py)
совпадает с собственной реализацией головного устройства.
